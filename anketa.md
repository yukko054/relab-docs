## Зачем вопросы 7, 8 и 12

Это обработчики персональных данных — их надо перечислить в политике.
Resend (США) и GitHub с резервными копиями (США) — зарубежные: для
152-ФЗ это трансграничная передача, юрист должен это увидеть. «Не знаю» —
тоже ответ: проверим по настройкам сервера, не читая сами значения.

  стираются.
- Резервные копии базы и файлов — зашифрованные, в приватном репозитории
  GitHub (США).
- Журнал действий: IP и время каждого входа и каждого действия в Relab Check.
