## Зачем вопросы 7, 8, 11 и 13

Это обработчики персональных данных — их надо перечислить в политике.
Resend и сервис ИИ-помощника (OpenCode, opencode.ai) — зарубежные: для
152-ФЗ это трансграничная передача, юрист должен это увидеть. «Не знаю» —
тоже ответ: проверим по настройкам сервера, не читая сами значения.

## Что уже известно

- Сервер — Reg.Ru CloudVPS, Россия → в политике «Россия», обработчик
  «ООО «Регистратор доменных имён РЕГ.РУ»» (сверить по договору).
- Push — Apple Push Notification service и Firebase Cloud Messaging: им
  уходит только токен устройства и текст уведомления.
- ИИ-помощник Трекера: на opencode.ai уходят вопрос, имя спрашивающего,
  названия, статусы и сроки задач, имена исполнителей, последний
  комментарий. Логин не уходит. Переписка хранится на нашем сервере, пока
  пользователь её не удалит.
- Резервные копии базы и файлов — зашифрованные, в приватном репозитории
  GitHub (США).
- Журнал действий: IP и время каждого входа и каждого действия в Relab Check.
