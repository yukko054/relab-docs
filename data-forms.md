# Анкеты о данных: App Privacy (Apple) и Data safety (Google)

Ответы сверены с кодом приложения 04.10.2026. Новое разрешение или новый вид
данных в приложении — пересмотреть эти анкеты.

## Какие данные собирает приложение

Всё — для работы приложения, связано с пользователем, без трекинга, рекламы
и аналитики. Apple: раздел «Data Linked to You».

| Тип данных | Google Play | Apple | Зачем |
|---|---|---|---|
| Имя, логин, почта | Личные данные: имя, email, ID пользователя | Contact Info: Name, Email; Identifiers: User ID | вход, кто провёл проверку |
| Фото и видео | Фото и видео | User Content: Photos or Videos | доказательства в пунктах |
| Аудиозаписи | Аудио: голос или звук | User Content: Audio Data | доказательства в пунктах |
| Точное местоположение | Местоположение: точное | Location: Precise Location | отметка места ответа, только по нажатию |
| Ответы проверки, комментарии, подписи | Действия в приложении / другой контент | User Content: Other User Content | сама проверка |
| Push-токен устройства | ID устройства или другие идентификаторы | Identifiers: Device ID | уведомления о назначении |

## Apple — App Privacy

| Вопрос | Ответ |
|---|---|
| Собираете ли вы данные? | Да — типы из таблицы выше |
| Используются для отслеживания (tracking)? | Нет |
| Связаны с личностью пользователя? | Да, все |

## Google — Data safety, остальные вопросы

| Вопрос | Ответ |
|---|---|
| Приложение собирает или передаёт данные пользователя? | Да |
| Данные передаются третьим лицам? | Нет. Push доставляют Apple и Google как обработчики по поручению: в уведомлении название проверки и объект |
| Данные шифруются при передаче? | Да, только HTTPS |
| Обязательные или по выбору | Геопозиция — по выбору (только по нажатию «Геопозиция» в пункте); фото, видео, аудио — когда пункт их требует; остальное — для работы приложения |
| Пользователь может запросить удаление данных? | Да: в приложении — запрос администрации по почте. Результаты проверок остаются у компании как рабочие записи («часть данных хранится по законным причинам») |
| Контакты, календарь, СМС, файлы на устройстве, галерея | Не собираются |

## Google — прочее

| Раздел Play Console | Ответ |
|---|---|
| Реклама | Нет |
| Целевая аудитория | 18+ |
| Контент-рейтинг (IARC) | Рабочее приложение: насилия, азартных игр, общения пользователей между собой нет |
| Доступ к приложению (App access) | Нужен вход: логин и пароль демо-аккаунта + инструкция из [store-listing.md](store-listing.md) |
| Фоновая геопозиция, foreground service | Нет — деклараций не нужно |
| Удаление аккаунта | Приложение аккаунты не создаёт; в приложении — запрос по почте. Если анкета потребует веб-ссылку — завести страницу с тем же текстом |
